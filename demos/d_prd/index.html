需求背景

1.1 现状问题

🔴 引导完成率低
  • 现有引导为 5 步式弹窗引导，整体完成率仅 38%
  • 第 3 步开始出现明显流失拐点（步骤留存率降至 55% 以下）
  • 用户反馈："步骤太多，不知道在引导什么"
🟡 价值感知弱
  • 引导内容偏功能介绍（"点击这里可以 XX"），缺乏场景化价值传递
  • 用户完成引导后，对产品核心价值的认知提升不显著（调研显示仅 29% 用户能准确描述产品核心价值）
🔴 跳出率高
  • 引导期间用户跳出率（未完成即离开）达 47%
  • 对比竞品均值（约 32%），存在明显优化空间

1.2 改版动因

维度现状目标方向
步骤数5 步压缩至 3 步
内容形式功能罗列式场景故事化
交互方式强制弹窗渐进式嵌入
跳出控制无干预智能挽留 + 断点续接

功能描述

3.1 整体架构

本次改版采用 「渐进式引导 + 场景驱动」 的设计理念：

┌─────────────────────────────────────────────┐ │ 新用户引导流程 v2.0 │ ├─────────────────────────────────────────────┤ │ │ │ Step 1: 价值预告 │ │ ┌──────────┐ │ │ │ "3 秒了解 │ → 一句话 + 动效展示 │ │ │ 核心价值"│ 产品能为你做什么 │ │ └──────────┘ │ │ ↓ │ │ Step 2: 核心操作 │ │ ┌──────────┐ │ │ │ "动手试一试"│ → 嵌入式高亮 + 引导蒙层 │ │ └──────────┘ 用户在真实界面完成一次 │ │ ↓ │ │ Step 3: 个性化定制 │ │ ┌──────────┐ │ │ │ "选你关心的"│ → 快速偏好设置（可选跳过） │ │ └──────────┘ │ │ │ │ ⚡ 支持断点续接：中途退出后下次自动恢复 │ │ ⚡ 智能挽留：检测到离开意图时弹出轻量提示 │ │ │ └─────────────────────────────────────────────┘

3.2 各步骤详细设计

Step 1：价值预告（预计 5-8 秒）核心

目标：让用户在 10 秒内理解产品核心价值

交互形式：

  • 全屏/半屏沉浸式卡片（非传统弹窗）
  • 动态展示产品核心场景（3-4 个关键画面轮播）
  • 底部固定 CTA：「开始体验」按钮
「[产品名] 帮你 [核心动作]，[价值结果]。」

Step 2：核心操作引导（预计 10-15 秒）核心

目标：用户在真实界面完成一次核心操作，建立肌肉记忆

交互形式：

  • 嵌入式蒙层高亮（非遮挡式）
  • 箭头 + 简短文字提示（≤8 个字）
  • 用户必须点击/操作才能进入下一步（强制互动）
设计原则：只引导 1 个最核心的操作 · 高亮区域要精准 · 操作成功后给予即时正反馈（微动效 + 「搞定！」）

Step 3：个性化设置（可选，预计 5-10 秒）可跳过

目标：快速收集用户偏好，用于后续个性化推荐

  • 卡片式多选（最多 3-5 个选项）
  • 明确提供「跳过」入口（右上角或底部）
  • 选择后即时生效，无需额外确认

3.3 断点续接机制

触发条件：用户在引导过程中退出（关闭页面/切换后台超过 30s）

恢复逻辑：

  1. 记录用户最后完成的步骤序号（本地存储）
  2. 下次打开时检测到未完成状态
  3. 以轻量 Toast 或顶部横幅提示：「继续上次引导？」
  4. 用户确认后从断点步骤恢复；忽略则标记为放弃

3.4 智能挽留策略

触发信号（满足任一即触发）：

  • 用户在单步停留超过 15 秒无操作
  • 检测到用户鼠标移向关闭按钮/返回键
  • 页面失去焦点（切换标签页）

挽留形式：非模态轻提示，文案示例：「还有 1 步就能解锁全部功能，继续吗？」

频率限制：单次引导流程最多触发 1 次挽留

3.5 分群策略（Demo 设定）

用户群体判断依据引导差异点
自然流量utm_source=null / 直接访问标准 3 步流程
广告投放utm_source 含广告标识Step 1 强化广告承诺的价值验证
移动端User-Agent 判断适配触摸操作（更大点击区域）
PC 端User-Agent 判断支持键盘快捷键跳转
注：分群策略的颗粒度和具体规则需根据实际业务数据调整，此处仅为 Demo 示例。

4.3 评估指标

主指标（用于决策）

指标定义统计方法显著性要求
引导完成率完成全部步骤用户数 / 进入引导用户数两样本比例检验p < 0.05，且 Cohen's h > 0.2

护栏指标（用于风险监控）

指标警戒阈值行动策略
注册转化率相对下降 > 3%立即回滚
引导跳出率相对上升 > 10%排查原因，必要时回滚
客诉增量日均新增 > 5 单人工抽样分析反馈内容
页面性能 (FCP)增加 > 500ms排查前端渲染瓶颈

4.4 决策规则与时间线

实验组胜出条件（需同时满足）：

  1. 主指标显著优于 Control 组（p < 0.05）
  2. 所有护栏指标均在安全范围内
  3. 效应量具备业务意义（完成率绝对提升 > 5pp）

4.5 样本量估算

基于当前基线 38%、目标提升至 58%（效应量 ≈ 0.4），α=0.05、β=0.2（80% 统计功效）
  • 每组所需样本量：约 340 人（完成引导的用户）
  • 考虑 38% 完成率：总曝光量需约 1,800 人/组
  • 14 天实验周期：日均新用户需 > 130 人
