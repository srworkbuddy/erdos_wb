WorkBuddy · 连接器演示

WorkBuddy 接入企业微信

把 AI 桌面智能体，装进你的企业微信
🔒 安全合规 ⚡ 5 分钟完成 🤖 零代码接入

▎前置条件

  • 电脑已安装 WorkBuddy，并开启 Claw 远程控制功能
  • 拥有一个可创建智能机器人的企业微信账号（无账号可参考「创建 & 注册企业」新建）

▎接入流程总览（长连接模式 · 先建后绑）

企微入口→ 手动创建→ API 模式→ 长连接配置→ 取凭据→ WorkBuddy 绑定→ 找到机器人→ 联通测试
1
进入企微「智能机器人」
从工作台找到智能机器人应用入口
  • · ① 点击左侧「更多」
  • · ② 在应用列表中选「工作台」
  • · ③ 顶部搜索「智能机器人」并打开
  • · ④ 进入后点击「创建机器人」
📷 截图 1：企微工作台 → 智能机器人 → 创建机器人
2
选择「手动创建」
在弹窗中跳过 AI 自动生成，选手动创建（便于精确配置）
✅ 推荐使用「手动创建」，可精确控制机器人名称、可见范围和 API 模式；「AI 帮你自动生成」适合快速搭建场景化机器人。
  • · 在「你需要一个什么样的机器人」弹窗中点击左下角「手动创建 >」
📷 截图 2：「AI 帮你自动生成」弹窗 → 点击「手动创建」
3
切换到「API 模式创建」
把创建模式从普通模式切换到 API 模式
  • · 在创建智能机器人页面右下角，点击「API 模式创建」
  • · 切换后，页面会显示「API 配置」区域，用于选择连接方式与凭据
提示：API 模式暂不支持预览与测试，调试需到绑定 WorkBuddy 后通过企微聊天窗进行。
📷 截图 3：创建机器人页 → 点击「API 模式创建」
4
配置可见范围 + 选择长连接
设置谁能使用这个机器人，并选择连接方式
  • · 填写机器人名称（建议「WorkBuddy 助手」），上传头像
  • · 点击「修改」配置可见范围：选择可使用该机器人的成员、部门或标签
  • · 在「API 配置」区域，连接方式选择「使用长连接」（推荐）
✅ 长连接模式无需域名/IP，也不用回填 Webhook URL；URL 回调适合需要自有域名接收消息的场景。
📷 截图 4：API 配置页 → 修改可见范围 + 选「使用长连接」
5
获取 Bot ID 与 Secret
保存凭据，用于在 WorkBuddy 端绑定
  • · Bot ID：系统已自动生成，点击右侧图标复制
  • · Secret：点击「点击获取」生成，复制保存（仅展示一次，关闭后需重新获取）
  • · 底部点击「保存」完成机器人创建
⚠️ 注意：Secret 属敏感凭据，演示截图已做打码处理；外部客户演示时建议同步打码，避免泄露。
📷 截图 5：Bot ID + Secret 配置区域
6
打开 WorkBuddy「企微助理集成」
回到 WorkBuddy 客户端，找到企微集成入口
  • · 打开 WorkBuddy，进入「助理设置」
  • · 找到「企微助理集成」这一项
  • · 点击右侧的「配置」按钮
📷 截图 6：WorkBuddy「助理设置」→ 企微助理集成 → 点「配置」
7
WorkBuddy 完成注册绑定
选择长连接 + 快捷绑定接入
  • · 在「注册企微助理通道」弹窗中选择「WebSocket 长连接」
  • · 点击「快捷绑定接入」（最简方式，无需手动填凭据）
  • · 扫码授权后，点击「注册」完成绑定，集成状态变为「已连接」
✅ 若快捷绑定失败，可手动填入上一步获取的 Bot ID 与 Secret 完成绑定。
📷 截图 7：WorkBuddy 注册企微助理通道弹窗（WebSocket 长连接 + 快捷绑定接入）
8
联通测试
在企微通讯录中找到机器人，发消息验证打通
  • · 在企微左侧「通讯录」下找到「智能机器人 → 企业创建的 → WorkBuddy Bot」
  • · 点击右侧「发消息」
  • · 发送一条简单消息（如「你好」），WorkBuddy 收到后返回回复 = 对接成功
📷 截图 8：企微通讯录中找到 WorkBuddy BOT，点「发消息」

✅ 企微接入完成！

现在你可以在企业微信中直接给 WorkBuddy 发任务了

▎常见问题

Q1：机器人没有响应？
检查 WorkBuddy 是否正在运行、Claw 服务是否开启；核对企微侧连接方式（长连接 vs URL 回调）与 WorkBuddy 端是否一致；长连接核对 Bot ID 和 Secret。
Q2：长连接注册失败？
确认企微侧已选择「使用长连接」；重新复制 Bot ID 和 Secret，避免带入多余空格；若 Secret 已失效，在企微后台重新获取后再次注册。
Q3：长连接与 URL 回调该选哪个？
推荐优先使用「WebSocket 长连接」，配置步骤更少、无需部署 IP 和回填 Webhook URL；URL 回调适合需要自有域名接收消息的场景。
Q4：可见范围设置后部分成员无法使用？
在企微「智能机器人 → 管理」中检查可见范围配置；确认所选成员、部门或标签已正确添加；修改后需让成员退出原会话并重新发起对话。
