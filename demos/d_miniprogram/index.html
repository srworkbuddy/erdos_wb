WorkBuddy 是什么？

一个 AI 编程助手，你用自然语言描述需求，它直接产出可运行的代码和文档

对话即开发

不需要从零写代码。你告诉 WorkBuddy 想要什么，它会：

  • 生成完整的项目代码（WXML/WXSS/JS/JSON）
  • 生成高保真预览页，浏览器直接看效果
  • 生成开发教程文档，方便团队理解维护
  • 支持多轮对话迭代，随时调整修改

开发流程

五步从需求到上线

下面是 WorkBuddy 完成这个美食推荐小程序的真实流程

1

💬 对话提需求

用一句话告诉 WorkBuddy 要做什么，它会理解需求并规划项目结构
// 用户输入 做一个小程序开发的demo // WorkBuddy 规划 // → 主题：美食推荐小程序 // → 4 个页面：首页 / 分类 / 我的 / 详情 // → 创建 22 个文件的项目结构
产出：
完整项目目录 miniprogram-demo/
入口配置 app.js / app.json / app.wxss
4 个页面 × 4 个文件（wxml/wxss/js/json）
工具函数 utils/util.js
2

👀 生成可视化预览

WorkBuddy 额外生成一个 HTML 预览页，用浏览器就能看到小程序长什么样，不用打开开发者工具
产出：
preview.html — 4 个手机界面高保真预览
搜索栏、Banner 轮播、分类网格、美食列表
左右联动分类页、个人中心、详情页下单栏
3

📖 生成开发教程

同步生成一份介绍页，讲解项目结构、核心代码、知识点，方便交付给客户或团队
产出：
guide.html — 10 章开发教程
intro.html — 客户介绍方案页
4

🛠️ 导入微信开发者工具

把 WorkBuddy 生成的代码文件夹导入微信开发者工具，配置 AppID，编译预览
操作：
微信开发者工具 → 导入项目 → 选择 miniprogram-demo/
填入自己的 AppID（或选「测试号」）
添加 tabBar 图标，或注释掉 iconPath 用纯文字 tab
点击编译 → 模拟器看到真实运行效果
5

🚀 上传 & 发布上线

在开发者工具上传代码，到微信公众平台提交审核，通过后发布
操作：
开发者工具点「上传」→ 填版本号 → 提交代码包
登录 mp.weixin.qq.com → 版本管理 → 提交审核
微信团队审核（通常 1-7 天）
审核通过 → 发布 → 用户可搜索使用
